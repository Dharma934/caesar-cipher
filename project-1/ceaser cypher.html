How Does the Caesar Cipher Work?

The Caesar Cipher is a simple encryption technique that shifts each letter in a message by a fixed number of positions in the alphabet.

For example, with a shift of 3:

A → D, B → E, C → F

The alphabet wraps around when it reaches the end:

X → A, Y → B, Z → C

Spaces, numbers, and special characters are not changed.
